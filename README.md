# AI Office 사내 작업 안내서

이 저장소는 사외 개발 환경에 접근할 수 없는 사내 PC에서, AI Office 프로젝트와 관련된
점검·구현·측정 작업을 진행하기 위한 안내서 모음입니다. 코드는 들어있지 않으며,
전체 문서는 한국어 마크다운입니다. 사내 PC의 코딩 에이전트(OpenCode)와 사람이
같이 참고합니다.

## 문서 목록

- [`01-llm-check.md`](01-llm-check.md) — 사내 LLM·임베딩·리랭커 연결 상태를 점검하는 스모크 체크 실행 방법
- [`02-token-measure.md`](02-token-measure.md) — 생성 시간이 어디서 쓰이는지 토큰/시간 지표로 측정하는 방법
- [`03-claims-spec.md`](03-claims-spec.md) — 정리된 리포트 md에서 주간 주장 목록("주장 300줄")을 만드는 구현 명세
- [`04-export-rules.md`](04-export-rules.md) — 결과를 사외로 가져갈 때 지켜야 하는 반출 규칙
- [`05-docling-speed.md`](05-docling-speed.md) — docling 변환 속도 개선 설정, 표는 필요한 문서만 나중에 추출
- [`06-triage.md`](06-triage.md) — 매일 들어오는 리포트를 빠르게 선별하고, 필요한 문서의 필요한 페이지만 docling에 넘기는 흐름

## 전체 흐름과 권장 순서

```
PDF (하루 ~200건)
 → 선별: PyMuPDF 빠른 읽기 + 관련/애매/무관 (06)
 → 범위 지정: 규칙, 확신 없을 때만 사내 LLM (06)
 → docling: 남길 페이지만, 표 구조 인식 끔 (05)
 → 정리된 md → 주장 추출 "주장 300줄" (03)
 → (분석 대상 문서만) 표 추출 (05)
```

① 사내 LLM·임베딩·리랭커 점검(01) → ② 선별·범위 지정 구현(06) → ③ docling 설정 적용(05) →
④ 주장 추출 구현(03) → ⑤ 소요 시간·토큰 측정(02) → ⑥ 반출 규칙에 따라 결과 정리(04)
